# v52b deployment

1. Back up the current repository if desired.
2. Extract `aim-cg-v52b.zip`.
3. Replace the current app files with the contents of the ZIP and commit/push to GitHub.
4. Allow the normal GitHub Pages workflow to complete.
5. On the phone/iPad, fully refresh Jobsched. If the old layout remains, close and reopen the installed PWA/browser tab so the v52b service-worker cache activates.

No Supabase SQL migration is required for this update.
